# Slot clusterer samples

`d29e766ea7580b8063c4f47b29e872db40a4d979`, used as test data for `src/samples.test.ts`
(plan Phase 2, task 3: the slot clusterer tested on hand-picked Servier and Bioicons
samples). Ten are Servier Medical Art drawings (CC BY 3.0, https://smart.servier.com), ten
come from other Bioicons authors.
